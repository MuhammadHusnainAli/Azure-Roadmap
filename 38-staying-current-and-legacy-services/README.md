# 38 · Staying Current and Legacy Services

> Tracks: E ○ A ● C ● · Part F · Architecture, Consulting and Career

Azure changes every week, and Azure AI changes fastest. This final topic covers:
- How to track change, and how to read old and new product names.
- What has retired or is retiring, and the migration targets.
- How to handle an inherited legacy AI, data or compute stack.
- How to evaluate and communicate Preview features.
- A glossary of every acronym and term in the roadmap.

It turns the roadmap from a snapshot into a habit of staying current.

## What you will be able to do

- Run a personal and organisational change-tracking routine with official sources.
- Translate legacy product names into current ones and spot successor products.
- Identify retired and retiring services in an estate and plan migrations.
- Assess and migrate inherited Assistants API, prompt flow, Semantic Kernel, AutoGen and hub-based systems.
- Plan data platform modernisation towards Fabric while delivering AI value early.
- Apply a consistent Preview feature policy and communicate it to clients.
