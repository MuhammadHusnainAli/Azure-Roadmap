# 37 · Capstone Projects

> Tracks: E ● A ● C ○ · Part F · Architecture, Consulting and Career

Ten capstones turn the roadmap into evidence. Each capstone follows the same pattern: a realistic brief, numbered requirements, a target architecture, milestones with deliverables, and acceptance evidence for your portfolio. They build on each other:
- Capstone 01's landing zone hosts the workloads.
- Capstone 02's RAG assistant is hardened by capstone 08's GenAIOps pipeline.
- Capstone 06's gateway can front capstones 02–04 and 07.

All company names are fictional. Use synthetic or public data only.

## What you will be able to do

- Deploy a governed, private Azure foundation from code.
- Build production-grade RAG, multi-agent, voice and document-processing solutions.
- Run a generative AI gateway with quotas, failover and chargeback.
- Build and govern a secure MCP server.
- Automate evaluation, red teaming and monitoring in CI/CD.
- Review an architecture and run a simulated client engagement end to end.

## Prerequisites

The topics listed in each capstone's "Skills practised" section, an Azure subscription with budget alerts, and a GitHub account.
